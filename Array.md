# Logic Building

## Move Zeroes to End

- swap the non zero element to the front use two pointer(use j as counter)

## Remove duplicates from sorted array

- use two pointers similar to move zeroes to end.(use j as counter)

## Find missing number

- use xor 

## Union of two sorted arrays

- use two pointers , one point to each array and one point to the result array.

## Intersection of two sorted arrays
- use two pointers , in equal case add to result , otherwise inc pointers
